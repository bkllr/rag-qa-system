# 小米 MACE 深度学习推理框架

MACE（Mobile AI Compute Engine）是小米开源的移动端深度学习推理框架，专为移动设备优化。

## 项目概述

- **GitHub**: https://github.com/Xiaomi/mace
- **开发语言**: C++ 为主，支持 Python 模型转换
- **支持平台**: Android、Linux、Windows、macOS
- **支持芯片**: 高通骁龙、联发科、ARM Mali、Apple

## 核心特性

1. **高性能**: 针对 ARM NEON 和 GPU 进行深度优化
2. **低延迟**: 支持模型量化，减少内存占用和推理延迟
3. **多设备支持**: 支持手机、IoT 设备等多种硬件平台
4. **模型转换**: 支持 TensorFlow、Caffe、ONNX 等模型格式转换

## 使用流程

1. **模型转换**: 将训练好的模型转换为 MACE 格式
2. **模型部署**: 将转换后的模型部署到目标设备
3. **推理执行**: 在设备上运行推理

## 应用场景

- 相机实时滤镜与人像美化
- 语音识别与自然语言处理
- AR/VR 场景中的实时推理
- IoT 设备上的边缘 AI 计算
