# 代码审查最佳实践

## 审查清单

- [ ] 逻辑正确性
- [ ] 边界条件处理
- [ ] 错误处理是否完整
- [ ] 命名是否清晰
- [ ] 是否有重复代码
- [ ] 是否符合项目规范

## 提交粒度

每个 commit 应该只做一件事：

```bash
git commit -m "feat: 添加用户注册接口"
git commit -m "fix: 修复邮箱验证正则表达式"
git commit -m "refactor: 提取公共验证逻辑"
```

## 审查注释格式

```
[建议] 这里可以用列表推导式简化
[必须] 缺少空值检查
[优化] 这个循环可以提取为单独函数
```
