# HTTP 状态码参考

| 状态码 | 含义 |
|:--|:--|
| 200 | OK - 成功 |
| 201 | Created - 创建成功 |
| 301 | 永久重定向 |
| 304 | 未修改（缓存）|
| 400 | Bad Request |
| 401 | Unauthorized |
| 403 | Forbidden |
| 404 | Not Found |
| 422 | Unprocessable Entity |
| 429 | Too Many Requests |
| 500 | Internal Server Error |
| 502 | Bad Gateway |
| 503 | Service Unavailable |
